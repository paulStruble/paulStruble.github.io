Project 1: Colorizing the Prokudin-Gorskii Collection

Overview

This project involved colorizing photographs from the digitized Prokudin-Gorskii collection of glass plate images. The collection includes various photos each separated into three grayscale color channels (R/G/B). The goal was to develop an algorithm to combine these grayscale channels into a single color photograph.

Approach

The initial naive algorithm calculates a displacement vector for each of the red and green color channels of the image with the goal of aligning each of them with the blue color channel. For each of the red and green channels, an exhaustive sliding window over displacement vectors in the range (-w, -w) to (w, w) is calculated, where w is some user-specified window size. For each displacement vector, the red/green channel is translated according to the vector, both the red/green and blue channels are cropped to remove any border artifacts, and a loss function is calculated over the two channels. I tried L1, L2, and NCC loss functions and ultimately decided on L2 for my final algorithm (which I found to work best). Additionally, an activation/feature map may be calculated over both the red/green and blue channels before the loss is calculated. In my final algorithm, I use an edge-detection filter described below in the "Bells and Whistles" section. Of all displacement vectors in the window, the one that produces the lowest loss value is used for the channel. The final image is constructed by combining the blue, translated red, and translated green channels (all of which are uncropped).

A modified version of the algorithm is used to support larger images. This version implements an "image pyramid" that recursively downscales the image, and performs a sliding window search over each scale of the image (starting with the most downscaled version). The displacement vector of the next lower-scaled image is used as a center/starting point for the sliding window of the current image scale. The size of the sliding window also scales dynamically with the image scale so that more downscaled images search over a larger sliding window while higher-resolution images only search over a smaller sliding window of pixels.

Bells and Whistles

Edge Detection:

I modified the algorithm to use an edge detection activation map over each color channel before calculating the l2 loss between the activation maps. The edge detector feature first applies a Gaussian blur to the color channel and then applies the Canny edge detector (both use the OpenCV implementaiton). It significantly improves results for some images where color intensity varies significantly between channels.
